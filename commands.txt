================================================================
  1. ЧЕМ ЗАПУСКАТЬ — ЧЕТЫРЕ ТОЧКИ ВХОДА
================================================================

ОКНО (графическая оболочка)
  python gui_app.py            с консолью, видно ошибки
  pythonw gui_app.py           без консольного окна

  Сворачивается в трей, а не закрывается.
  Кнопка НАСТРОЙКИ в заголовке — ключи, режим, навыки.

КОНСОЛЬ (терминальная Герта, команды со слэшем)
  python herta_cli.py

TELEGRAM-МОСТ
  python telegram_app.py

  Внимание: один токен — один процесс. Если мост запущен
  дважды, Telegram начнёт отдавать 409 Conflict.

СТАРАЯ КОНСОЛЬ / ГОЛОС (main.py)
  python main.py                     текстовый диалог
  python main.py --voice             микрофон → распознавание → ответ → голос
  python main.py --live-voice        Google Live API, нативное аудио
  python main.py --text "вопрос"     один вопрос и выход
  python main.py --doctor            самодиагностика
  python main.py --no-tts            без озвучки
  python main.py --tts-test          проверить голос
  python main.py --output-test       проверить устройство вывода
  python main.py --list-devices      список микрофонов
  python main.py --list-output-devices   список динамиков


================================================================
  2. КОМАНДЫ В КОНСОЛИ (herta_cli.py)
================================================================

Всё, что НЕ начинается со слэша, уходит Герте как реплика.

  /help                  список команд
  /skills                показать навыки (● включён, ○ выключен)
  /skills off study      выключить навык
  /skills on study       включить навык
  /model                 показать текущего провайдера и модель
  /model cerebras        переключить провайдера
  /model ollama qwen2.5:7b   переключить вместе с моделью
  /memory                что Герта помнит о тебе
  /context               сколько занято контекста
  /clear                 забыть текущий разговор (память не трогает)
  /doctor                самодиагностика
  /exit                  выйти

Выйти также можно по Ctrl+C.


================================================================
  3. КОМАНДЫ БОТА В TELEGRAM
================================================================

  /help        что умеет и что доступно именно тебе
  /start       то же самое
  /whoami      твой chat id и роль (владелец или гость)
  /reset       забыть текущую переписку
  /voice       переключить режим голосовых ответов
                 mirror  — голосом только в ответ на голосовое
                 always  — всегда голосом
                 never   — только текстом
  /impression  что Герта о тебе думает
  /forgetme    стереть свой профиль и мнение о себе

Только владельцу:

  /admin           панель: провайдер и модель, активные навыки,
                   зрение и поиск, режим голосовых, кто пишет
                   и сколько, сколько профилей с мнением
  /skills          список навыков (🟣 включён, ⚪ выключен)
  /skills off study    выключить навык
  /skills on study     включить обратно
  /people          список известных людей

Переключение навыка сбрасывает активные сессии, поэтому изменение
доходит и до тех, кто уже переписывался.

Можно присылать голосовые — распознает и ответит голосом.
Можно присылать фото — разберёт, если включено зрение.


================================================================
  4. ГЛОБАЛЬНЫЕ ХОТКЕИ (работают из любого приложения)
================================================================

  Ctrl+Shift+H     показать или спрятать окно
  Ctrl+Shift+D     диктовка: удерживай, говори, отпусти —
                   текст напечатается туда, где курсор
  Ctrl+Shift+V     включить или выключить голосовой режим
  Ctrl+Shift+A     отправить Герте выделенный в редакторе фрагмент

Если хоткеи не поднялись — запусти от администратора.
Меняются в .env: HOTKEY_SUMMON, HOTKEY_DICTATION,
HOTKEY_VOICE_TOGGLE, HOTKEY_ASK_SELECTION.


================================================================
  5. ЧТО ГОВОРИТЬ ГОЛОСОМ ИЛИ ТЕКСТОМ
================================================================

Эти фразы разбираются локально, до отправки в модель.

ПАМЯТЬ
  «запомни, что меня зовут Влад»
  «что ты обо мне помнишь»
  «забудь, что меня зовут Влад»

ПОИСК В ИНТЕРНЕТЕ
  «найди в интернете X», «погугли X», «новости про X»
  «какая погода в Москве», «что такое X», «кто такой X»

КОД
  «проверь типы в файле main.py»       (mypy)
  «линтуй actions/code_tools.py»       (ruff)
  «прогони тесты»                      (pytest)
  «открой main.py», «открой config.py на 120 строке»
  «перейди к ошибке», «открой первую находку»

Можно просить несколько дел сразу:
  «проверь типы в gui_app.py, потом прогони ruff,
   потом открой первую находку»

ЗРЕНИЕ
  «что у меня на экране»
  «посмотри на экран и скажи, что не так»

УПРАВЛЕНИЕ КОМПЬЮТЕРОМ
  «открой браузер», «открой ютуб», «открой почту»
  «сделай громче», «поставь на паузу», «следующий трек»
  «скопируй это», «что в буфере»
  «переключись на VS Code», «найди файл X»
  «создай папку X», «создай заметку X»

ТЕРМИНАЛ (только белый список, с подтверждением в окне)
  «покажи git status», «покажи git log»
  «что установлено» (pip list)

WAKE WORD (в голосовом режиме)
  Герта отвечает, только услышав имя:
  «Герта, ...», «Эй Герта, ...», «Великая Герта, ...»
  Минуту после её ответа можно говорить без имени.


================================================================
  6. НАВЫКИ
================================================================

Лежат в папке skills/, по файлу SKILL.md на каждый.

  code       разбор кода, типы и стиль, тесты, переход к ошибке
  study      учёба: ведёт к пониманию, а не выдаёт готовый ответ
  research   изучение нового: поиск, сверка источников, конспект

Включать и выключать:
  в консоли — /skills on|off <имя>
  в окне    — кнопка НАСТРОЙКИ, раздел «Навыки»

Выключенный навык остаётся на диске и возвращается одним щелчком.
Состояние хранится в data/skills_state.json.

Свой навык: создай папку skills/<имя>/ с файлом SKILL.md,
скопировав заголовок из любого существующего.


================================================================
  7. УСТАНОВКА И ОБСЛУЖИВАНИЕ
================================================================

  powershell -ExecutionPolicy Bypass -File .\install.ps1
                                 установка (спросит, что ставить)
  .\install.ps1 --tier voice     сразу с голосом
  .\install.ps1 --dry-run        примерка, ничего не ставит

  python doctor.py               проверить, что поднялось

Ключи API вписываются в .env либо задаются в окне настроек —
тогда они лягут в системное хранилище, а не в файл проекта.


================================================================
  8. ЕСЛИ ЧТО-ТО НЕ ТАК
================================================================

Бот в Telegram молчит
  Проверь, что процесс жив и один:
    Get-Process python | Format-Table Id, StartTime
  Перезапусти telegram_app.py.

Окно не открывается
  Запусти через python gui_app.py (не pythonw) и посмотри ошибку.

Герта отвечает не в характере на локальной модели
  Проверь OLLAMA_NUM_CTX в .env: меньше 8192 обрезает персону.

Не хватает видеопамяти
  Локальная модель и голосовой режим вместе в 6 ГБ не помещаются.
  Выбери что-то одно либо переключись на облако.

Голос дефолтный вместо её собственного
  Не поднялся RVC. Проверь пути RVC_APPLIO_ROOT и RVC_MODEL_PATH.
